# MACHT - Minimum Viable Strength

> An offline-first, minimalist powerlifting tracker built as a Progressive Web App (PWA). No accounts, no bloat.

## Beta Testing

MACHT is currently in Beta. 

**Access the live beta here:** [https://BenWassa.github.io/macht/](https://BenWassa.github.io/macht/)

### Beta Tester Instructions
1. **Mobile First**: This app is designed to be used on your phone at the gym.
2. **Install as App (PWA)**: 
   - **iOS**: Open the link in Safari, tap the Share button (square with an arrow pointing up), and select "Add to Home Screen".
   - **Android**: Open in Chrome and tap "Add to Home Screen" when prompted, or find it in the browser menu.
3. **Offline Mode**: Once loaded, the app works entirely offline. All data is saved strictly to your device's local storage.
4. **Data Management**: Use the Backup feature in the Profile panel to export your data periodically if you want to be safe during the beta.

## Features
- Clean, minimalist interface
- E1RM tracking
- Rest timers
- Plate math visualizer
- Injury tracking and substitution logic
- Completely private (Local Storage only)

## Development
This is a Vite + React + Tailwind + Zustand project.

```bash
# Install dependencies
npm install

# Run local dev server
npm run dev

# Build for production
npm run build
```
